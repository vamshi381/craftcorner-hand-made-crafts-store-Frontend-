# 🎨 CraftCorner - Handmade Crafts E-Commerce Website

CraftCorner is a modern **React.js based E-Commerce Web Application** for buying and selling handmade crafts. The application provides a beautiful shopping experience for customers along with a complete Admin Dashboard to manage products, categories, orders, users, and contact messages.

---

# 📖 Project Overview

CraftCorner allows users to browse handcrafted products, search and filter products, manage their shopping cart and wishlist, place orders, write reviews, and manage their profile.

An Admin Panel is also included for managing the complete store.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/your-username/CraftCorner.git
```

Go inside project

```bash
cd CraftCorner
```

Install dependencies

```bash
npm install
```

Start React

```bash
npm run dev
```

Start JSON Server

```bash
npx json-server --watch db.json --port 5000
```

Open

```
http://localhost:5173
```
